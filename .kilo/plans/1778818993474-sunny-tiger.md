## Step 2: Implement `src/procureos_mcp/config.py`

Create environment-based database configuration.

Implementation details:

- Import `os`.
- Import `load_dotenv` from `dotenv`.
- Call `load_dotenv()` once at module load so local `.env` values are available.
- Add a small helper named `get_required_env(name: str) -> str`.
- Read these variables:
  - `DB_HOST`, required
  - `DB_PORT`, optional, default `5432`
  - `DB_NAME`, required
  - `DB_USER`, required
  - `DB_PASSWORD`, required
- Expose `DB_CONFIG` as a dictionary suitable for `psycopg2.connect(**DB_CONFIG)`.

Target shape:

```python
"""Configuration loading for the ProcureOS MCP server."""

import os

from dotenv import load_dotenv

load_dotenv()


def get_required_env(name: str) -> str:
    """Return a required environment variable or fail with a clear error."""
    value = os.getenv(name)
    if not value:
        raise RuntimeError(f"Missing required environment variable: {name}")
    return value


DB_CONFIG = {
    "host": get_required_env("DB_HOST"),
    "port": int(os.getenv("DB_PORT", "5432")),
    "database": get_required_env("DB_NAME"),
    "user": get_required_env("DB_USER"),
    "password": get_required_env("DB_PASSWORD"),
}
```

Notes:

- This intentionally fails early if required credentials are missing.
- `DB_PORT` defaults to PostgreSQL's standard port.
- No real secrets should be hardcoded.
- `config.py` must not import MCP, `server.py`, or database connection modules.

## Step 4: Implement `src/procureos_mcp/server.py`

Create the MCP server entrypoint.

Implementation details:

- Import `FastMCP` from `mcp.server.fastmcp`.
- Import `register_database_tools` from `procureos_mcp.tools.database_tools`.
- Create a module-level MCP instance named `mcp`.
- Register database tools once at module load.
- Define `main() -> None` to run the MCP server.
- Use the standard `if __name__ == "__main__": main()` guard.

Target content:

```python
"""ProcureOS MCP server entrypoint."""

from mcp.server.fastmcp import FastMCP

from procureos_mcp.tools.database_tools import register_database_tools

mcp = FastMCP("procureos-db-server")

register_database_tools(mcp)


def main() -> None:
    """Run the ProcureOS MCP server."""
    mcp.run()


if __name__ == "__main__":
    main()
```

Rules:

- `server.py` should not contain SQL queries.
- `server.py` should not load or manage database credentials directly.
- `server.py` should only create the MCP server, register tools, and run it.
